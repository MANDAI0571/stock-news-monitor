## 負けた原因（数字で見た結論）

勝率は50%（3勝3敗）ありました。負けたのは**損大利小**だからです。

| | 平均 | 内訳 |
|---|---:|---|
| 勝ち3回 | +31,967円 | +2.3% / +4.5% / +5.8% |
| 負け3回 | −80,333円 | −10.7% / −12.2% / −7.3% |

損益比 **0.40**。この比率では勝率50%でも資金は減ります。原因は2つ、どちらも仕組み側の問題でした。

1. **損切りが効いていなかった。** ルールは−7%だったが、実際の決済は−8.6% / −10.9% / −12.7%。
   「前日に宣告 → 翌営業日の寄付で約定」という仕組みのため、宣告した時点ですでに−7%を割っており、
   翌日の寄付でさらに滑っていた。

2. **勝ちを伸ばす前に切っていた。** 6回の決済のうち利確（+15%）に到達したものは**0回**。
   勝った2つ（9513 電源開発 +4.5%、5901 東洋製罐 +5.8%）はどちらも、
   まだ上昇の途中で**10営業日のタイムアウトに強制決済**されていた。
