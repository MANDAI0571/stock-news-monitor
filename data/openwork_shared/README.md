# OpenWork確認済みデータ（Codex・Claude共用）

このフォルダーをOpenWork数値の唯一の共用保存先とします。

## 共用ファイル

- `openwork_scores.csv`
  - Codex版300万円運用、Claude版300万円運用、各note下書きが共通で読みます。
  - 会社コードごとに最後に確認した正常値を1行保存します。
- `openwork_cache.csv`
  - 詳細8項目を含むキャッシュです。生成後に配置されます。
- `openwork_scores_meta.json`
  - 更新日などのメタ情報です。生成後に配置されます。

## 更新ルール

- 新しい確認値がある会社だけ更新します。
- 未取得や異常値で過去の正常値を消しません。
- `fetched_at` と `source_url` を残します。
- 評価値は1.0〜5.0、回答者数は1以上の整数です。
- 外部サイトの自動巡回は行わず、正規に確認できた値だけを保存します。

旧保存先 `data/openwork_scores.csv` が残っている場合は、移行期間中のみ
互換読込みします。新規データはこの共用フォルダーへ保存します。
